# 📝 MyBlog - Consumo de API com Fetch JS

Este é um projeto de blog responsivo que consome dados de uma API externa para exibir posts e comentários. Desenvolvido durante meus estudos de JavaScript Assíncrono no canal **Hora de Codar**.

## 🚀 Tecnologias Utilizadas

*   **JavaScript (ES6+):** Uso intensivo de `Async/Await` e `Fetch API`.
*   **HTML5 & CSS3:** Estrutura e estilização com foco em legibilidade.
*   **JSONPlaceholder:** API fake para simulação de requisições reais.

## 🛠️ Funcionalidades

- [x] Carregamento dinâmico de posts (GET).
- [x] Página individual para cada post via parâmetros de URL.
- [x] Carregamento simultâneo de post e comentários usando `Promise.all`.
- [x] Simulação de envio de novos comentários (POST).
- [x] Sistema de "loading" para melhor experiência do usuário (UX).

## 💡 O que eu aprendi / pratiquei

Este projeto foi fundamental para consolidar conceitos que vão além da sintaxe básica:

*   **Manipulação de DOM:** Criação dinâmica de elementos para renderizar os dados da API.
*   **Async/Await:** Gestão de requisições assíncronas para evitar o "Callback Hell".
*   **Padronização:** Implementação rigorosa de ponto e vírgula e boas práticas de clean code.
*   **Tratamento de Dados:** Como converter respostas de servidor para objetos manipuláveis via `.json()`.
